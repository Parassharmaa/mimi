# Open licenses and attribution

This benchmark is public and composed entirely of material distributed under
open licenses or public-data terms. It does not have one homogeneous upstream
license, so the Hugging Face metadata uses `license: other`.

Mimi-authored selection metadata, manifests, result summaries, and the database
arrangement are released under [CC BY-SA
4.0](https://creativecommons.org/licenses/by-sa/4.0/). This does not replace
the license attached to an upstream row. Each row retains its source corpus,
identifier, license, and attribution/provenance fields.
